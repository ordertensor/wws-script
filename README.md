## 核心战术亮点 (v2.8.0)

* **纯裸属性战力 Cost 与边际效用递减模型**：
* **裸战力基准**：排阵战力消耗严格锚定舰船自身的裸三维属性之和（ $\sum \text{specs}$ ），不将词缀加成与道具虚高计入战力 Cost；
* **非线性凸边际惩罚**：引入递增边际成本函数 $C = P_{\text{裸战力}} + (100m + 60m^2)$，单槽装配 1 件道具仅需补偿 160 战力，装配 2 件边际惩罚飙升至 280，杜绝为了节省几点微薄战力而挥霍 2~3 件消耗品的极端现象，自适应锁定低战力与少道具的最佳平衡点。


* **相邻指向增益（Directional Buffs）联动匹配**：
* **站位协同**：在战力同分时，算法优先选择相邻增益激活数最多的阵容（例如左侧带有向右增益的巡洋舰配合右侧战列舰），最大化面板利用率；
* **【团队协作】物理接入验证**：单卡槽位必须真正接入相邻卡牌的左右指向增益时才允许挂载“团队协作”修改器，孤立槽位物理禁用，防止无效消耗。




* **战略资产掉落确权（解耦可控）**：
* **💎煤炭与🔧快速维修包 95% 独立防线**：精准识别敌方槽位的隐藏掉落物，针对战略资源启用 95% 胜率硬确权，严防翻车丢矿；


* **动态可配置**：深卡池与大后期玩家可在面板自由取消该选项，无缝退回全局统一胜率推演。


* **关底 Boss 战绝对全歼与进度代币装配**：
* **100% 满胜率绝对优先**：Boss 战解除战力压制限制，卡池排序反转为战力降序，王牌大卡倾巢而出以自身硬面板确保 100% 全歼，绝不为了贪收益而接受 95% 风险；
* **精准挂载【效率提升】**：在 100% 胜率前提下，后处理管线仅对真正产出代币的对位卡槽精准装配“效率提升”，并彻底清除不加代币的“士气打击”；
* **Boss 战半自动安全拦截**：全自动模式推演到 Boss 战填槽完毕后自动暂停挂起，留给玩家手动核对插槽与开战的最终确认权。


* **背包资产绝对安全与出战清洁锁**：
* **零代买消耗**：彻底移除了后台自动扣减活动货币的购买接口，杜绝擅自花费代币；


* **战前无损去冗**：出战提交前进行物理清洁校验，若单卡加效率已能达成目标，自动剔除多余的增益品；满血 3 HP 舰船在开启节省模式时物理拦截快速维修包。




* **人机交互与视觉工程**：
* **操作流极简收敛**：合并旧版冗余按钮，收拢为“手动模式（选卡填槽）”与“自动模式（自动游玩）”；
* **全量中英双语战报**：内置盟军全 30 艘舰艇与全部修改器的中英双语格式化输出，战报一目了然；


* **自由拖拽毛玻璃控制台**：面板支持顶部拖拽位移，避开游戏核心界面与战场卡槽。

## 控制台面板开关说明

| 配置选项 | 默认状态 | 功能描述 |
| --- | --- | --- |
| **全歼模式** | `关` | 开启后即使阶段击杀数达标，也会强制清空阶段内所有剩余据点再推进；关闭时达标即切入下一阶段。 |
| **消耗品节省模式** | `开` | 启用边际效用递减算法平衡战力与道具用量；开启时满血 3 HP 舰船禁用维修包以节约资源。 |
| **战略资产确权** | `开` | 针对掉落煤炭与快速维修包的槽位启用 95% 特化胜率防线；卡池深厚时可关闭退回常规基准。|
| **Boss 战代币优先** | `开` | 关底 Boss 必须在 100% 全歼前提下，后处理管线优先在代币槽位强力装配【效率提升】修改器。 |
| **Boss 战仅自动选卡** | `开` | 自动游玩遇到 Boss 战时，自动完成最优大卡推演与填槽，随后主动暂停，交由玩家手动开战。 |

## 快速上手指南

### 1. 手动模式 (选卡)

* 点击面板上的 **【手动模式 (选卡)】** 按钮；
* 脚本会根据当前据点（若在网页中点开了特定据点则优先锁定该据点）计算出最优卡牌搭配与消耗品配置，直接填充至网页棋盘中；
* **不会发起任何战斗网络请求**，供玩家直观检查或手动调整卡槽后自行点击游戏内的“战斗”按钮。

### 2. 自动模式 (游玩)

* 点击面板上的 **【自动模式 (游玩)】** 按钮；
* 脚本按威胁度阶梯依次推演当前阶段据点，自动填卡、发起出战、轮询结算并推进至下一阶段；


* 当推演至最终关底 Boss 战时（若勾选了“Boss 战仅自动选卡”），脚本会将最优阵型填入棋盘并**弹出警示暂停**，由玩家在网页端做最后确认并手动开战。

## 故障排查与运行须知

* **搜索看似卡住或需要重置**：
* 可随时点击红色的 **【停止】** 按钮中断计算；
* 中断后脚本会安全退出事件循环，并保留最近一次推演到的有效阵容草稿；


* 若因浏览器标签页切入后台导致事件循环休眠，刷新游戏网页即可重置上下文。




* **开战门禁熔断 (Safe Gatekeeper)**：
* 若在极端词缀限制下，手牌无论如何组合均无法达到设定的安全开战线（常规 90% / 煤炭 95% / 代币 100%），自动模式会触发**门禁一票否决**；


* 脚本将暂停自动出战并保留当前最高胜率草稿，避免盲目送死造成主力残血甚至灭队。
